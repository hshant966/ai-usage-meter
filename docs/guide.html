The six views

What each label means

TODAY28.4M

Tokens used today across every AI tool (Claude Code, Codex, Hermes). A token is a chunk of text, roughly ¾ of a word. Most of a coding session's tokens are re-read context, so this number climbs fast and is not the same as your limit.

5H RESET3h29

Countdown to your 5-hour limit reset. Claude Code's short-term limit runs in 5-hour windows. When this hits zero, the 5H % goes back to 0.

5H34%

How much of the current 5-hour allowance you've used. Green under 65%, orange from 65%, red from 90%.

PACE~113%

Where 5H % will land at reset if you keep working at today's speed. It is used ÷ fraction of window passed. Above 100% means you will run out before the reset. It appears once 30 minutes of the window have passed.

WEEK17%

Weekly limit used. A separate, larger allowance across all 5-hour windows in a 7-day period. Running out here blocks you until the weekly reset.

WK RESET29m

Countdown to the weekly reset.

Make limits last

Using Claude efficiently

  1. Watch PACE, not 5H %. 40% used in the first hour is a problem; 40% in the fourth hour is fine. PACE shows which one you are in.

  2. Start fresh between unrelated tasks. Every message re-sends the whole conversation. Use /clear when you switch topics, and /compact when a long session is still on the same task.

  3. Match the model to the job. Bigger models use your allowance faster. Use /model to pick a lighter one for renames, small fixes and questions, and save the largest for design and hard debugging.

  4. Be specific about files. "Fix the date bug in format.js" costs far less than "look through the project and find bugs", because Claude reads less.

  5. Use subagents on purpose. Each one starts with its own fresh context and can use tens of thousands of tokens. Ask for them for real parallel work, and give them a token cap.

  6. Plan heavy work after a reset. If 5H RESET says 20m and you are at 85%, wait and start the big task in the new window.

  7. Check /usage inside Claude Code for the official numbers. The meter reads the same source every 5 minutes.
